# DATABASES: Gym Management System

This repository contains the Database and Web Application project developed for the Databases (Bases de Dados) course in the 2nd Year, 1st Semester at the Faculty of Engineering of the University of Porto (FEUP). 

The project consists of a comprehensive Gym Application that manages fitness facilities, training sessions, members, and instructors. It is structured around two distinct academic submissions, progressing from initial conceptual data modeling to a fully functional full-stack web implementation.

## Project Overview

The system is designed to handle the operational needs of a gym, ensuring data integrity through relational constraints, foreign keys, and cascading actions. It provides a robust backend database accessed through a dynamic web interface for end-users and administrators.

**AI-Assisted Development:** A specific requirement of this course project was to actively utilize Artificial Intelligence tools (such as LLMs) during the development process. AI was leveraged as a learning and coding assistant to help validate relational algebra logig and generate data used to populate the database.

## First Submission: Conceptual & Logical Design

The first phase of the project focuses on modeling the data requirements.

* **UML / Conceptual Model:** Visual representation of the core entities (Members, Trainers, Classes, Memberships) and their relationships.

## Second Submission: Physical Implementation

The second phase brings the theoretical model to life through SQL implementation.

* **Relational Algebra:** Formulation of the main system queries using relational algebra expressions to validate the schema's viability.
* **Database Creation:** SQL scripts for creating tables.
* **Data Population:** SQL scripts to populate the database with comprehensive initial test data.

## Technologies Used

* **Database:** SQLite
* **Design & Modeling:** UML
